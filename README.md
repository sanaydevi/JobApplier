# JobApplier

Recovery and development of a local AI-assisted job discovery, ranking, and resume-tailoring dashboard.

## Status
The original dashboard and recovered Python modules are available as a local recovery archive, but the end-to-end discovery and AI pipeline is not yet verified. The historical 100-job index is not a current live-job feed.

## Privacy
Do not commit `.env`, API keys, personal resumes, generated tailored resumes, or application history. Keep these on your own computer.

## Local run
Install Python, configure `.env` locally, and use `run_jobapplier.bat` from the recovery archive. This repository is being rebuilt.
